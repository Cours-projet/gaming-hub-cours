# 📝 Changelog - PlayHub

## Version 2.0.0 - Open World Survival (Mars 2026)

### 🎮 Changements Majeurs
- **Transformation complète** : Passage de Battle Royale à Open World Survival
- **Monde ouvert** : Carte de 3000x3000 pixels avec génération procédurale
- **Système de craft** : Plus de 10 recettes d'outils et structures
- **Survie** : Gestion de la faim, soif et santé

### ✨ Nouvelles Fonctionnalités

#### Monde & Exploration
- Génération procédurale de 260+ ressources
- 4 types de ressources : Arbres, Rochers, Minerai de fer, Buissons
- Cycle jour/nuit avec effets visuels
- Mini-map en temps réel
- Caméra fluide qui suit le joueur

#### Système de Craft
- Menu de craft interactif (touche C)
- 3 catégories : Outils, Structures, Fonderie
- Recettes progressives (bois → pierre → fer)
- Vérification automatique des ressources
- Interface violette moderne

#### Outils
- **Pioches** : Bois (2x), Pierre (3x), Fer (5x)
- **Haches** : Bois (2x), Pierre (3x)
- Système d'équipement (touches 1-5)
- Affichage visuel de l'outil équipé

#### Structures
- **Table de craft** : Débloque recettes avancées
- **Four** : Fonderie pour transformer le minerai
- **Coffre** : Stockage (base implémentée)
- Placement libre avec touche F
- Rendu 3D avec ombres et détails

#### Système de Survie
- **Santé** : 100 HP avec régénération
- **Faim** : Diminue avec le temps (-1/5s)
- **Soif** : Diminue avec le temps (-1/5s)
- Mort si faim ou soif à 0
- Buissons pour restaurer faim/soif

#### Interface
- Notifications visuelles en jeu
- Chat avec horodatage
- Barres de vie sur ressources
- Affichage de l'outil équipé
- Stats en temps réel (sidebar)

### 🎨 Design
- Thème noir minimaliste conservé
- Accent violet (#8b5cf6) sur tous les éléments
- Ressources avec ombres et détails
- Structures avec effets 3D
- Joueur avec yeux et animations

### 🔧 Améliorations Techniques
- Optimisation du rendu (culling hors écran)
- Système de caméra fluide
- Gestion des collisions
- Performance stable à 60 FPS
- Code modulaire et maintenable

### 📚 Documentation
- README.md mis à jour
- GUIDE-JEU.md créé avec tutoriel complet
- Commentaires dans le code
- Recettes documentées

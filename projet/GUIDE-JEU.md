# 🎮 Guide du Jeu - PlayHub Survival

## 🌍 Monde Ouvert

Le jeu se déroule dans un monde de **3000x3000 pixels** avec :
- Génération procédurale de ressources
- Cycle jour/nuit
- Mini-map en temps réel
- Caméra qui suit le joueur

---

## 🌲 Ressources Disponibles

### Arbres (Bois)
- **Apparence** : Tronc marron avec feuillage vert
- **Récolte** : Main ou Hache (plus rapide)
- **Donne** : 3-5 bois
- **Utilité** : Craft d'outils et structures

### Rochers (Pierre)
- **Apparence** : Bloc gris rectangulaire
- **Récolte** : Main ou Pioche (plus rapide)
- **Donne** : 2-4 pierre
- **Utilité** : Craft d'outils en pierre et four

### Minerai de Fer
- **Apparence** : Roche marron avec points orange brillants
- **Récolte** : Pioche uniquement
- **Donne** : 1-2 minerai de fer
- **Utilité** : Craft d'outils en fer (après fonderie)

### Buissons (Nourriture)
- **Apparence** : Buisson vert avec baies rouges
- **Récolte** : Main
- **Donne** : +10 Faim, +5 Soif
- **Utilité** : Survie

---

## 🔨 Système de Craft

### Recettes de Base (sans table)
Appuyez sur **C** pour ouvrir le menu de craft.

- **Pioche en bois** : 5 bois
- **Hache en bois** : 5 bois

### Avec Table de Craft
Craftez d'abord une table de craft (10 bois), puis placez-la avec **F**.

- **Pioche en pierre** : 3 bois + 5 pierre
- **Hache en pierre** : 3 bois + 5 pierre
- **Pioche en fer** : 3 bois + 5 minerai de fer
- **Four** : 20 pierre
- **Coffre** : 15 bois

### Fonderie (Four requis)
Construisez un four, puis utilisez-le pour fondre :

- **Lingot de fer** : 1 minerai de fer

## ⚒️ Outils et Efficacité

| Outil | Vitesse de Récolte | Dégâts |
|-------|-------------------|--------|
| Main | 1x | 5 |
| Pioche/Hache Bois | 2x | 8 |
| Pioche/Hache Pierre | 3x | 12 |
| Pioche Fer | 5x | 18 |

**Astuce** : Utilisez la hache pour les arbres et la pioche pour les rochers/minerai!

---

## 🏗️ Structures

### Table de Craft
- **Coût** : 10 bois
- **Utilité** : Débloque toutes les recettes avancées
- **Placement** : Appuyez sur **F** après craft

### Four
- **Coût** : 20 pierre
- **Utilité** : Transforme le minerai en lingots
- **Placement** : Appuyez sur **F** après craft

### Coffre
- **Coût** : 15 bois
- **Utilité** : Stockage (à venir)
- **Placement** : Appuyez sur **F** après craft

---

## 💚 Système de Survie

### Santé (HP)
- **Maximum** : 100 HP
- **Perte** : Faim/Soif à 0
- **Régénération** : Si Faim > 50 et Soif > 50

### Faim
- **Maximum** : 100
- **Diminution** : -1 toutes les 5 secondes
- **Restauration** : Manger des buissons (+10)

### Soif
- **Maximum** : 100
- **Diminution** : -1 toutes les 5 secondes
- **Restauration** : Manger des buissons (+5)

## 🎮 Contrôles

| Touche | Action |
|--------|--------|
| **ZQSD** ou **Flèches** | Se déplacer |
| **E** | Récolter ressource proche |
| **C** | Ouvrir/Fermer menu craft |
| **F** | Placer structure |
| **1-5** | Équiper outil (1=Main, 2-5=Outils craftés) |
| **ESC** | Fermer menu |

---

## 🎯 Progression Recommandée

1. **Début** : Récoltez 10 bois avec vos mains
2. **Craft** : Fabriquez une pioche et une hache en bois
3. **Récolte** : Utilisez les outils pour récolter plus vite
4. **Table** : Craftez une table de craft (10 bois)
5. **Outils Pierre** : Améliorez vos outils (pierre > bois)
6. **Four** : Construisez un four (20 pierre)
7. **Fer** : Minez du fer avec une pioche
8. **Outils Fer** : Craftez les meilleurs outils!

---

## 💡 Astuces

- Les outils en fer sont 5x plus rapides que vos mains!
- Gardez toujours de la nourriture (buissons) à portée
- La mini-map montre toutes les ressources
- Les structures peuvent être placées n'importe où
- Le cycle jour/nuit est purement visuel (pas d'ennemis la nuit)

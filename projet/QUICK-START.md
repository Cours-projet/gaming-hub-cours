# 🚀 Quick Start - PlayHub Survival

## Démarrage Rapide

### 1. Lancer le Serveur
```bash
npm install && node index.js
```

### 2. Ouvrir dans le Navigateur
```
http://147.79.21.126:57010
```

### 3. Jouer!
Cliquez sur "Jouer Solo" ou "Multijoueur"

---

## 🎮 Premiers Pas (5 minutes)

### Minute 1 : Récolte de Base
1. Utilisez **ZQSD** pour vous déplacer
2. Approchez-vous d'un arbre (vert)
3. Appuyez sur **E** pour récolter
4. Récoltez **10 bois**

### Minute 2 : Premier Craft
1. Appuyez sur **C** pour ouvrir le menu
2. Cliquez sur "CRAFT" pour la **Pioche en bois** (5 bois)
3. Cliquez sur "CRAFT" pour la **Hache en bois** (5 bois)
4. Appuyez sur **ESC** pour fermer

### Minute 3 : Équiper et Récolter
1. Appuyez sur **2** pour équiper la pioche
2. Récoltez des **rochers** (gris) avec **E**
3. Appuyez sur **3** pour équiper la hache
4. Récoltez plus d'**arbres** avec **E**

### Minute 4 : Table de Craft
1. Récoltez jusqu'à avoir **10 bois**
2. Appuyez sur **C**
3. Craftez la **Table de craft**
4. Appuyez sur **F** pour la placer

### Minute 5 : Outils Avancés
1. Appuyez sur **C**
2. Craftez une **Pioche en pierre** (3 bois + 5 pierre)
3. Équipez-la avec **2**
4. Récoltez plus vite!

---

## 🎯 Objectif Principal

**Craftez une Pioche en Fer!**

1. ✅ Récoltez du bois
2. ✅ Craftez pioche/hache en bois
3. ✅ Récoltez de la pierre
4. ✅ Craftez une table de craft
5. ✅ Craftez une pioche en pierre
6. ✅ Minez du minerai de fer (roches marron avec points orange)
7. ✅ Craftez un four (20 pierre)
8. ✅ Fondez le minerai en lingots
9. ✅ Craftez la pioche en fer!

---

## 💡 Astuces Essentielles

- 🌲 **Hache** = Arbres (plus rapide)
- 🪨 **Pioche** = Rochers et Fer (plus rapide)
- 🍓 **Buissons** = Restaurent faim/soif
- 🗺️ **Mini-map** = En haut à droite
- 📦 **Inventaire** = Sidebar à droite
- 🔔 **Notifications** = En haut au centre

---

## ⚠️ Survie

- Votre **faim** et **soif** diminuent avec le temps
- Mangez des **buissons** (verts avec baies rouges)
- Si faim/soif = 0, vous perdez de la vie!
- Restez bien nourri pour régénérer

## 🔨 Recettes Rapides

### Sans Table
- **Pioche bois** : 5 bois
- **Hache bois** : 5 bois

### Avec Table
- **Pioche pierre** : 3 bois + 5 pierre
- **Hache pierre** : 3 bois + 5 pierre
- **Pioche fer** : 3 bois + 5 minerai
- **Four** : 20 pierre
- **Coffre** : 15 bois

## 🆘 Problèmes Courants

### "Je ne peux pas récolter le fer!"
→ Utilisez une **pioche** (pas la hache, pas la main)

### "Je ne vois pas certaines recettes"
→ Craftez et placez une **table de craft** d'abord

### "Ma faim/soif est à 0!"
→ Récoltez des **buissons** (verts avec baies rouges)

### "Je ne sais pas quel outil j'ai équipé"
→ Regardez la **sidebar à droite** ou l'**icône** près du joueur
